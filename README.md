# 🎬 Cinistream

Cinistream is a Netflix-inspired movie streaming web application that allows users to browse, explore, and view movie details with a modern and responsive UI.

---

## 🚀 Features

- 🎥 Browse trending and popular movies
- 🔍 Search functionality
- 📄 Movie details with modal view
- ⚡ Fast performance using Vite
- 📱 Fully responsive design
- 🧩 Reusable React components
- 🔄 API integration for real-time data

---

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript (ES6+)
- CSS Modules
- Movie API (TMDB or alternative)
